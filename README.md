# 人狼の館

マンションの管理人に雇われた調査員として、101〜106号室の家具や道具を調べ、住人に話を聞く一人用の2D探索ゲームです。事件は1件です。人狼の正体は固定ですが、潜伏先は調査への反応で変わります。

## 起動

ファイルを取得し、ブラウザで `index.html` を開いてください。単独配布には `standalone.html` を使えます。どちらも通信やパッケージの追加は不要です。

## 5日間の遊び方

1. 「調査を始める」を選び、廊下のドアから入室します。狭い画面では廊下を横にスクロールできます。
2. 家具や道具の絵を選ぶと外観を確認できます。証拠がありそうなら「詳しく調べる」を選びます。住人への聞き込みも可能です。無実の住人が自分の秘密について嘘をつくこともあります。
3. 行動力は1日5です。入室はその日その部屋の初回だけ1、詳細調査と聞き込みは各1、音源の照合は2を消費します。外観確認、再入室、推理ノートは無料です。同じ家具の詳細調査と同じ住人への質問はその日各1回です。
4. 1〜4日目は「調査を終えて翌朝へ」で進めます。逃走があれば、翌朝に発生元がノートへ記録されます。現地で痕跡を詳しく調べると、何日目の夜にどちらへ進んだかが分かります。古い痕跡も調べられます。別の手順として、初夜の録音を入手して106号室の受信機で照合すると、その日の潜伏先を確定できます。
5. 5日目は「調査を終了して罠を配置」を選びます。捕獲罠は最大2室、封鎖罠と監視罠はそれぞれ最大1通路です。通路を選ぶには先に使う罠を切り替えます。同じ通路に封鎖罠と監視罠は置けません。作戦実行前なら再配置できます。
6. 作戦を実行できるのは一度です。人狼が反応して留まるか隣室へ移動した後、その部屋の捕獲罠が作動します。潜伏先と封鎖していない隣室を押さえると、留まる場合と逃げる場合の両方に備えられます。作戦を見送ると期限切れで敗北します。結果画面で正体、移動、監視結果を確認し、リトライできます。

## 実装

- `game.js` は行動力、時間、証拠、住人の証言とその真相、人狼の移動、捕獲を管理します。NPCの移動判定に渡すのは潜伏先、警戒度、観測した入室・調査、封鎖、発見した罠です。
- 警戒は潜伏先での入室、調査、聞き込み、強い証拠の発見で上昇します。50以上ならより危険の低い隣室へ、80以上なら移動可能な限り逃げます。夜に留まれば警戒が下がり、逃走後はリセットされます。作戦時の接近や目についた罠でも警戒が上がります。同じ条件では同じ経路を選びます。
- `ui.js`、`style.css`、`index.html` は2Dの廊下・室内、クリック可能な家具のSVG、ノート、罠配置、結果を表示します。 `node build.js` で単一HTMLを再生成できます。
- 推理ノートの証拠とメモは試合中に保持します。リロードやリトライで事件は最初から始まります。

## テスト

Node.js 22以上で `node test.js`。行動力、日付、警戒度、6室、証言、4種類の逃走痕、監視と封鎖、勝敗、期限切れ、リトライを検証します。800通りのシード付き探索手順で4日目まで進め、最後に痕跡または音源照合から罠を配置して捕獲できるか確認します。
