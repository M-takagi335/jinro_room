# jinro_room
人狼の部屋を探すゲーム

## 人狼の館

6室に潜む人狼2体を、住人の証言と数字調査で見つける1人用ブラウザゲームです。村人は必ず真実を話し、人狼は真実と嘘を使い分けます。

## 起動

リポジトリのファイルを取得し、ブラウザで `index.html` を開きます。通信や依存パッケージのインストールは不要です。`standalone.html` は単独で配布・実行できます。

## ルールと操作

1. 「調査を始める」を押します。部屋1〜6に人狼2体と村人4人がランダムに配置され、試合終了まで役職は固定です。
2. 各部屋の証言を読みます。役職についての証言は元の役職を指し、人数についての証言は発言時点の生存者を数えます。
3. 部屋の「調査」を押すと、隣接する生存人狼の合計が表示されます。例えば2号室の調査対象は1・3号室です。端の部屋の隣は1室です。調査は1日2回までで、同じ部屋はその日1回までです。「調査・証言・公開の履歴」から過去の日付と結果を確認できます。
4. 人狼と思う部屋の「封鎖」を押して確定します。1日に1室を封鎖でき、住人の正体が公開されて除外されます。除外された部屋を調査・封鎖することはできません。
5. 決着がつかなければ夜になります。「襲撃の結果を見る」を押すと生存村人のうち1人が襲撃され、部屋と正体が公開されます。人狼は、その日の有益な証言をした村人を優先します。
6. 封鎖後と襲撃後に勝敗を判定します。生存人狼が0体なら勝利です。人狼が残っていて生存村人数が生存人狼数以下なら敗北です。終幕の「もう一度遊ぶ」で新しい配置を抽選します。

「推理候補を見る」では公開情報に矛盾しない開始時の人狼配置を確認できます。自力で推理したい場合は閉じたまま遊べます。

## 技術構成

- `game.js` は試合の状態、NPCの戦略、証言の真偽判定、公開情報からの候補列挙を担当します。候補ごとに、仮に村人とみなした話者の証言を真とし、調査記録・役職公開と照合します。人数の照合には記録時点の生存部屋を使います。
- 昼の開始時には、公開情報に基づき、適切な調査を最大2回選べば封鎖すべき人狼を少なくとも1体確定できる証言の組を採用します。残りの調査をどこに使うかはプレイヤーが決めます。
- `ui.js`、`index.html`、`style.css` は表示と入力を担当します。スマートフォンでは部屋の列を横にスクロールできます。未公開の役職は通常の画面・UI向けのデータに含めません。ゲーム処理はすべてブラウザ内で実行します。
- `node build.js` でソース変更後に単一HTML版を再生成できます。

## テスト

Node.js 22以上で `node test.js` を実行します。全15配置それぞれで80シードを使い、計1,200試合を検証します。600試合は公開情報だけで調査先と封鎖先を選んで勝利し、残りは別の手順で勝敗と操作制約を検証します。
