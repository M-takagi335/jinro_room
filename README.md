# 人狼の館

記憶を失った調査対象者として、五人のNPCから話を聞き、自分の役職を当てる一人用のノベルゲームです。固定事件を3問収録しています。事件ごとにプレイヤーの正解役職や公開情報が変わります。

## 起動

ブラウザで `index.html` を開きます。 `standalone.html` は単体で起動でき、いずれも通信や追加のパッケージは不要です。

## 遊び方

1. タイトルから公開ルールへ進み、事件を選んで聞き取りを始めます。
2. NPCの役職を無料で確認します。名乗った役職に応じて質問が開きます。人狼も別の役職を名乗れます。
3. 共通質問と専門質問は合わせて8回までです。話した相手には戻れません。残りが0回でも、新しい相手の役職確認はできます。
4. 推理ノートで質問・回答、自称役職、公開情報に合う役職候補を確認できます。自分用の仮説は候補の計算やNPCの回答に影響しません。
5. 五人に聞き取りをしたら、自分の役職を回答します。他の五人は任意です。結果画面から事件の真相と推理の解説を確認できます。

役職の人数は村人2人、占い師・狩人・記録係・人狼が各1人です。人狼以外は知っていることを正直に話します。

## 実装とテスト

- `game.js` は固定事件、役職、質問、回答、状態遷移、推理候補の計算を担当します。可能な360配置を列挙し、仮に人狼でないと置いた話者の公開発言だけを制約として適用します。
- `ui.js`、`style.css`、`index.html` は会話、質問、ノート、最終回答、結果・解説を表示します。役職メニューは自称役職に基づいて構成します。
- `node build.js` で単一HTMLを再生成し、`node test.js` でテストします。Node.js 22で検証しています。テストには事件の答えが含まれます。

## 今後の改善候補

別事件の追加、候補の絞り込みを段階的なヒントとして見せる設定、プレイテストに基づく質問予算の調整。
